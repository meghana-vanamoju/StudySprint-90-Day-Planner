# StudySprint — 90-Day Study Planner

A dark, responsive React + Vite + TypeScript study dashboard for a 90-day DSA-first interview preparation plan. All progress is saved locally in the browser.

## Features

- Dashboard with study-day progress, completed tasks, study minutes, course lessons, and weekly focus.
- 90-day calendar with a prepared daily syllabus and clickable day selection.
- DSA problem tracker with title, pattern, difficulty, URL, notes, and Todo / Attempted / Solved status.
- Revision queue for unfinished problems and solved problems whose 1-, 7-, or 30-day review interval has passed.
- Course tracker for Udemy and other courses with editable lesson counts.
- Analytics for weekly study minutes, completed study days, and solved problems by pattern.
- Start-date settings, JSON export/import backup, and reset option.
- Responsive mobile navigation.
- Browser `localStorage` persistence; no backend or account required.

## Requirements

- Node.js 18.18+ (Node.js 20 LTS recommended)
- npm

## Run locally

```bash
# 1. Extract the ZIP and open the project folder
cd 90-day-study-planner

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Vite prints a local URL, usually `http://localhost:5173`. Open it in your browser.

## Production build

```bash
npm run build
npm run preview
```

The production build is generated in `dist/`.

## Data storage and backup

- Data is stored under the browser localStorage key `studysprint-90day-v1`.
- It stays in that browser profile and does not sync across browsers or devices.
- Open **Settings & backup → Export planner data** to save a JSON backup.
- Use **Import planner data** to restore a previously exported backup. Import replaces the current planner data.
- Clearing browser site data may erase progress; export a backup regularly.

## Personalize the plan

- Use **Settings & backup** to set Day 1.
- The preloaded roadmap lives in `src/App.tsx` in the `weeks` array.
- The daily 8:00–11:00 PM blocks are generated by `defaultTasks()`.
- The two Udemy course URLs and the RisingBrain / Whimsical links are prefilled from the supplied resources.
- Course lesson totals are editable when adding a course. The prefilled totals are placeholders to help track progress; update them to match the course sections you actually intend to complete.

## Workflow recommendation

Each evening: recall yesterday's concept → learn one concept → attempt two matching problems → review mistakes → log progress. If a problem is difficult, record the pattern and revisit it later rather than copying the solution.

## Notes

- This is a client-side personal planner, not a hosted website. To publish it, build the app and deploy `dist/` to a static hosting provider.
- External Google Fonts are used for typography; system font fallbacks are provided.
